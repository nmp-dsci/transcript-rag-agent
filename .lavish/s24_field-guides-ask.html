Ask for a guide the way you ask a question

The New guide panel is a form crammed into the bottom of a rail: topic field, scan, checklist, title, checkbox, button. It should be one box you talk into — the same composer and microphone Chat already has — that turns a question into a report. The same mic goes on the comment box, so feedback on a guide is spoken too.

Voice stack already shipped: mic → AudioWorklet → /ws/stt → Deepgram, useSpeechToText STT live on this server (/api/health.stt = true) Pipeline unchanged: scope → export → extract → compose → verify → publish

The panel competes with the library for 300px, the placeholder is cut off, the checklist scrolls inside a scrolling rail, and the page next to it is about something else entirely.

P1 It's a form, not a question

Users think "how do teams calibrate LLM judges against humans?", not "topic: llm-as-a-judge". The topic field forces the translation onto the user, and the title field asks them to name a report they haven't seen.

P2 Two clicks before anything happens

Find sources, then read a checklist, then Write guide. Nothing starts until the third action, and the checklist is the only feedback that the question was understood.

P3 No voice, no examples

Chat has a mic that streams speech into the box. Guides has neither the mic nor example questions to show what a good ask looks like.

P4 Wrong place

Composing a new report belongs in the main stage, like Chat's empty state — not squeezed under the library while an unrelated guide fills the screen.

02

Target behaviour

One composer, four moments. Every step is the shortest thing that keeps the agent honest about which videos it will read.

1 · askType or speak a questionPlain language. Enter or Build. The mic is the same green button as Chat.
2 · foundSources appear under the questionScope runs on submit (no LLM, ~1s). The card says "found 19 videos across 11 channels" with the list pre-selected. One click to build.
3 · buildingResearch map, guide in the railUnchanged from s23: the map shows every cluster reading, and the rail entry says ● extract.
4 · read + commentSpeak comments tooThe comment box gets the mic; Send to the agent runs in the Revisions tab while you keep reading.
The confirmation card stays. It is the one place the user sees which videos the agent will read in full before spending 15 minutes of subscription, and it is where a wrong retrieval (a "judge" that pulled in courtroom videos) gets caught. It just stops being a form: pre-selected, one button, editable if you care.
